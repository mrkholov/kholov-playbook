# kholov-playbook

Репозиторий отдаёт домен `kholov.me` через GitHub Pages (custom domain, файл `CNAME`).

- `job/playbook/` — лендинг с кейсами Егора (см. `README.md`).
- `index.html` в корне — временная заглушка-редирект на `/job/playbook/`. Корень домена
  зарезервирован под сервис поиска работы, который строится поверх этого же ядра кейсов.

## Бэклог

`BACKLOG.md`, а не теряется в переписке. Прежде чем закрыть тему словами «вернёмся
к этому позже» — добавь пункт в `BACKLOG.md` с датой и коротким контекстом, почему
отложили.
