# Бэклог

Темы, которые обсудили, но взяли не сейчас.

## 2026-09-04

- **Контент на корне `kholov.me`.** Пока редирект на `/job/playbook/`. Когда сервис
  поиска работы дойдёт до своего лендинга — корень станет его хабом.
- **Автосинхронизация резюме на hh.ru (было в плане пунктом 3).** В открытом API
  `hhru/api` нет методов на редактирование/публикацию резюме соискателем — есть только
  `employer_resumes.md` (резюме глазами работодателя). Обновлять резюме на hh.ru придётся
  руками; ядро данных может только подсказывать, что там поменять.
- **Мониторинг вакансий, отклики с письмом, переписка с работодателем (пункты 4–6).**
  Подтверждено: доступно через API с OAuth-скоупом `applicant` без отдельного одобрения
  (`negotiations`, `vacancies_for_applicant`). Можно проектировать сразу как «есть API».
- **Английская версия плейбука/сайта.** Закладываем как отдельный слой поверх того же
  ядра данных, делаем после того, как ядро наполнено и стабильно на русском.
- **Продуктовая гипотеза (сервис для чужого поиска работы).** Не валидируем, пока не
  отработает на самом Егоре — сначала личное использование, потом решение, стоит ли
  снимать Egor-специфичный контент и делать общий продукт.
- **Сбор имён и контактов эйчаров** со страниц вакансий и из уже полученных
  сопроводительных писем/переписки. Часть будущей зоны аутрича — писать им напрямую,
  а не только откликаться. Отдельный слой поверх «Входящих» (пункт 6 плана).
- **Разбор уже отправленных сопроводительных писем.** Взять письма, которые Егор уже
  слал под конкретные вакансии, сопоставить с тем, что спрашивали в вакансии, найти
  слабые места и вероятные причины отказов. Вход для обучения генератора писем
  (пункт 5 плана) и для доработки самого ядра — вскроет, каких данных/формулировок
  не хватает.
- **Раздел с вакансиями конкретных компаний, по зонам** (банки, беттинг, IT и т.д.) —
  найти карьерные страницы целевых компаний и собрать их в разделе сайта, разбитом
  по отраслям. Пример устройства страницы-списка — <https://talent.pm.group/jobs>
  (Parimatch, ATS Teamtailor: фильтры по удалёнке и по направлению).
  Для карточек конкретных вакансий — пример <https://talent.pm.group/jobs/8137364-senior-affiliate-manager>,
  форма отклика там модальная, поля не вытащить без реального захода в форму (Apply
  подгружает её через JS). Нужно подготовить для таких форм либо автозаполнение,
  либо блок с данными под копирование одним кликом — имя, контакты, ссылки, ответы
  на типовые скрининговые вопросы, сопроводительное письмо. Пересекается с пунктом 5
  плана, но здесь охват шире hh.ru — карьерные сайты компаний со своим ATS.
